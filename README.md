# 🎮 Simon Says Game

An interactive memory-based mini game built using **HTML, CSS, and JavaScript**.

This project challenges players to remember and repeat an increasingly complex sequence of colors.

> Simple mini project. Clean design. Smooth interaction.

---

## 🌟 Features

- 🎯 Random color sequence generation
- 🧠 Memory-based gameplay
- 📈 Level progression system
- ❌ Game over detection
- 🎨 Elegant interactive UI
- ✨ Smooth animations and effects
- ⚡ Lightweight and fast

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & animations
- **JavaScript (Vanilla JS)** – Game logic

---

## 🎮 How to Play

1. Press **any key** to start the game.
2. Watch carefully as a button flashes.
3. Click the button that flashed.
4. With each level, a new color is added to the sequence.
5. Repeat the full sequence correctly to level up.
6. If you click the wrong button → Game Over.

Try to reach the highest level possible! 🚀
